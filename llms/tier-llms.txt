# Tier (Dott)

> Tier — now operating as Dott after the 2024 merger of TIER Mobility and Dott — is a European micromobility operator running shared e-scooters and e-bikes across 400+ cities in Europe and the Middle East. It exposes a partner-facing, API-Key-gated Dott Partner API (GBFS-style vehicle/availability data) governed by a published API Licence. Backed by Northzone, Point Nine, and Speedinvest.

## APIs

- [Dott Partner API](https://ridedott.com/api-licence/): API-Key-gated partner data feed (GBFS-style vehicle availability). Requires a per-partner key issued via Dott's registration process; data host https://gbfs.api.ridedott.com returns HTTP 401 without authorization.
